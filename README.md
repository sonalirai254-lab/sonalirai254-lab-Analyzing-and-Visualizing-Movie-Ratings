# 🎬 Movie Rating Analysis Dashboard

An interactive Movie Rating Analysis Dashboard built using **Python** and **Streamlit**. This project analyzes movie datasets and provides meaningful insights through interactive visualizations.

## ✨ Features

- 📊 Movie rating distribution
- 🎭 Genre-wise analysis
- ⭐ Highest-rated movies
- 📈 Interactive charts and graphs
- 🔍 Dataset exploration
- 🎨 Clean and responsive Streamlit interface

## 🛠️ Tech Stack

- Python
- Streamlit
- Pandas
- NumPy
- Matplotlib
- Plotly

## 🚀 Installation

Clone the repository

```bash
git clone https://github.com/sonalirai254-lab/Analyzing-and-Visualizing-Movie-Ratings.git
```

Go to project directory

```bash
cd Analyzing-and-Visualizing-Movie-Ratings
```

Install dependencies

```bash
pip install -r requirements.txt
```

Run the application

```bash
streamlit run app.py
```
